# Restore drills (append-only)

*One dated receipt per restore drill: the backup restored into scratch, every database integrity-checked and every file checked. Never edited or pruned; a failed drill is a receipt too. The newest passed receipt older than its window is a clue for the next self-audit (`corpus/estate-structure.md`).*
